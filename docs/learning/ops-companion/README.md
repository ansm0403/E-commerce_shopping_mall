# Ops Companion (RN 앱) — 학습 노트

> **이 폴더는 무엇인가**
> [`docs/roadmap/ops-companion-design.md`](../../roadmap/ops-companion-design.md) 는 **설계와 결정의 기록**이다.
> Phase 별 계획, 기각된 대안, 물려받은 전제가 시간순으로 쌓여 있어 "무엇을 왜 정했는가"를 담는다.
>
> 이 폴더는 그 결과로 **실제로 짜인 코드**를, **React Native 를 처음 접한다는 가정**으로 다시 푼 것이다.
> 설계 문서가 *무엇을 하기로 했는지* 라면, 이 폴더는 *지금 저장소에 있는 코드가 어떻게 생겼고 왜 그런지* 다.

<br>

## 읽는 순서

| 장 | 파일 | 제목 | 짝지어 볼 코드 |
|---|---|---|---|
| 0~4 | [01-rn-first-app](./01-rn-first-app.md) | RN 첫 앱 — 개념부터 우리 코드까지 | `ops-companion/` 전체 |

한 편으로 끝난다. 앞에서부터 순서대로 읽으면 되고, 각 장이 앞 장의 개념에 의존한다.

- **0장**은 이 앱이 무엇이고 지금 어디까지 됐는지다. 여기만 읽어도 전체 그림은 잡힌다.
- **1장**은 React Native·Expo 용어다. 웹(React/Next.js) 경험을 기준으로 대응시켜 설명한다.
- **2~3장**이 본편이다. 파일을 하나씩 열어 "이 코드가 왜 이렇게 생겼는지"를 짚는다.
- **4장**은 로그인·목록 조회·토큰 자동 갱신 세 흐름을 그림으로 본다.
- **5~7장**은 웹과의 차이, 실제로 밟은 함정, 실행 방법이다.

<br>

## 전제

- **React 는 안다고 본다.** 컴포넌트, `useState`, `useEffect`, Context 는 설명하지 않는다.
- **React Native 는 모른다고 본다.** `View`, `StyleSheet`, SecureStore, Metro 같은 것은 처음 나올 때 설명한다.
- 백엔드 쪽(`backend/src/ops/`, `X-Client: mobile` 분기)은 이미 만들어져 운영에 배포된 상태를 전제한다.
  그 이야기는 설계 문서 §5.6·§5.1 에 있다.
